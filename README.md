# BLISS Hotel — Aqua Desktop

Segunda propuesta, actualizada con los seis elementos tropicales nuevos, lámpara de lava, tumbona, logo animado y favicon.

## Abrir localmente
Descomprime el ZIP completo y abre index.html. Conserva la carpeta assets junto a index.html, style.css, app.js y favicon.ico.

## Subir a GitHub Pages
1. Crea un repositorio en GitHub (público si utilizas GitHub Free).
2. Sube el contenido descomprimido del ZIP, no el ZIP. index.html debe quedar en la raíz del repositorio, no dentro de otra carpeta.
3. Guarda los archivos en la rama main.
4. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root). Pulsa Save.
5. Cuando termine la publicación, abre el enlace que aparece en Pages.

El archivo .nojekyll es intencional; permite servir directamente los archivos estáticos.
Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Contenido
- index.html: página completa.
- style.css: estilos de escritorio y celular.
- app.js: galería, formulario local y control del logo animado.
- favicon.ico y assets/favicon.png: iconos de pestaña.
- assets/: imágenes y video incluidos, con rutas relativas.

No requiere instalar dependencias, compilar, configurar un servidor ni iniciar sesión en ChatGPT.
El formulario prepara una solicitud descargable; no envía información al hotel ni confirma reservas.
